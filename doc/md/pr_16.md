## 5. Краткая теория

### 5.1. Зачем нужен массив товаров

В интернет-магазине обычно есть не один товар, а список товаров.

Один товар удобно описывать объектом:

```javascript
const product = {
  id: 1,
  title: 'Кофемашина Barista Home',
  category: 'kitchen',
  price: 19990,
  isAvailable: true
};
```

Но каталог товаров — это уже не один объект, а список объектов.

Такой список удобно хранить в массиве:

```javascript
const products = [
  {
    id: 1,
    title: 'Кофемашина Barista Home',
    category: 'kitchen',
    price: 19990,
    isAvailable: true
  },
  {
    id: 2,
    title: 'Электрический чайник SmartHeat',
    category: 'kitchen',
    price: 4990,
    isAvailable: true
  }
];
```

Массив позволяет:

- перебрать все товары;
- найти нужный товар;
- отфильтровать товары по категории;
- отобрать товары в наличии;
- отсортировать товары по цене;
- посчитать количество товаров;
- посчитать общую стоимость;
- подготовить данные для вывода карточек на страницу.

### 5.2. Объект товара

Каждый товар в массиве должен иметь одинаковую структуру. Это упрощает обработку данных.

Пример структуры товара:

```javascript
{
  id: 1,
  title: 'Кофемашина Barista Home',
  category: 'kitchen',
  price: 19990,
  discountPercent: 10,
  rating: 4.7,
  isAvailable: true
}
```

Рекомендуемые свойства:

| Свойство | Назначение |
|---|---|
| `id` | уникальный идентификатор товара |
| `title` | название товара |
| `category` | категория товара |
| `price` | цена товара |
| `discountPercent` | скидка в процентах |
| `rating` | рейтинг товара |
| `isAvailable` | наличие товара |

Важно, чтобы названия свойств были одинаковыми у всех товаров.

Плохо:

```javascript
const products = [
  { title: 'Товар 1', price: 1000 },
  { name: 'Товар 2', cost: 2000 }
];
```

Лучше:

```javascript
const products = [
  { title: 'Товар 1', price: 1000 },
  { title: 'Товар 2', price: 2000 }
];
```

Если структура объектов разная, функции поиска, фильтрации и сортировки будут работать нестабильно.

### 5.3. Условный оператор `if`

Условный оператор позволяет выполнить код только при определённом условии.

Пример:

```javascript
const product = {
  title: 'Кофемашина Barista Home',
  isAvailable: true
};

if (product.isAvailable) {
  console.log('Товар в наличии');
} else {
  console.log('Товара нет в наличии');
}
```

В интернет-магазине условия используются для:

- проверки наличия товара;
- проверки скидки;
- проверки выбранной категории;
- проверки строки поиска;
- проверки пустой корзины;
- проверки корректности формы.

### 5.4. Цикл `for`

Цикл `for` используется, когда нужно выполнить действие несколько раз.

Пример перебора массива:

```javascript
for (let i = 0; i < products.length; i += 1) {
  console.log(products[i].title);
}
```

Пояснение:

- `let i = 0` — начальное значение счётчика;
- `i < products.length` — условие продолжения цикла;
- `i += 1` — увеличение счётчика;
- `products[i]` — текущий товар.

Цикл `for` полезен для понимания того, как массив перебирается по индексам.

### 5.5. Цикл `for...of`

Цикл `for...of` позволяет перебрать элементы массива проще.

```javascript
for (const product of products) {
  console.log(product.title);
}
```

Пояснение:

- `product` — текущий элемент массива;
- не нужно вручную работать с индексом;
- код читается проще.

Для большинства учебных задач с товарами `for...of` понятнее, чем классический `for`.

### 5.6. Метод `forEach`

Метод `forEach` выполняет действие для каждого элемента массива.

```javascript
products.forEach(function (product) {
  console.log(product.title);
});
```

То же самое можно записать через стрелочную функцию:

```javascript
products.forEach((product) => {
  console.log(product.title);
});
```

`forEach` удобно использовать, когда нужно выполнить действие, но не нужно создавать новый массив.

Например:

- вывести товары в консоль;
- вывести названия товаров;
- добавить элементы на страницу.

### 5.7. Метод `map`

Метод `map` создаёт новый массив на основе исходного.

Пример: получить массив названий товаров.

```javascript
const productTitles = products.map((product) => {
  return product.title;
});

console.log(productTitles);
```

Короткая запись:

```javascript
const productTitles = products.map((product) => product.title);
```

`map` нужен, когда из одного массива нужно получить другой массив.

Например:

- массив названий товаров;
- массив цен;
- массив кратких описаний;
- массив HTML-элементов в будущей DOM-практике.

### 5.8. Метод `filter`

Метод `filter` создаёт новый массив только из тех элементов, которые прошли проверку.

Пример: получить только товары в наличии.

```javascript
const availableProducts = products.filter((product) => {
  return product.isAvailable;
});

console.log(availableProducts);
```

Короткая запись:

```javascript
const availableProducts = products.filter((product) => product.isAvailable);
```

Фильтрация нужна для:

- отбора товаров по категории;
- отбора товаров в наличии;
- отбора товаров со скидкой;
- отбора товаров по строке поиска.

### 5.9. Метод `find`

Метод `find` возвращает первый элемент массива, который подходит под условие.

Пример: найти товар по `id`.

```javascript
const productById = products.find((product) => {
  return product.id === 2;
});

console.log(productById);
```

Если товар не найден, результатом будет `undefined`.

Поэтому после `find` полезно делать проверку:

```javascript
if (productById) {
  console.log(productById.title);
} else {
  console.log('Товар не найден');
}
```

### 5.10. Метод `sort`

Метод `sort` сортирует массив.

Пример сортировки по возрастанию цены:

```javascript
const sortedProducts = [...products].sort((a, b) => {
  return a.price - b.price;
});

console.log(sortedProducts);
```

**Важно:** `sort` изменяет исходный массив. Поэтому в учебном проекте лучше сортировать копию:

```javascript
const sortedProducts = [...products].sort((a, b) => a.price - b.price);
```

Здесь:

- `[...products]` создаёт копию массива;
- `sort` сортирует копию;
- исходный массив `products` остаётся в прежнем порядке.

Для сортировки по убыванию цены:

```javascript
const sortedProducts = [...products].sort((a, b) => b.price - a.price);
```

Для сортировки по названию:

```javascript
const sortedProducts = [...products].sort((a, b) => {
  return a.title.localeCompare(b.title);
});
```

### 5.11. Метод `reduce`

Метод `reduce` позволяет свести массив к одному значению.

Пример: посчитать общую стоимость товаров.

```javascript
const totalPrice = products.reduce((sum, product) => {
  return sum + product.price;
}, 0);

console.log(totalPrice);
```

Пояснение:

- `sum` — накопленная сумма;
- `product` — текущий товар;
- `0` — начальное значение суммы;
- на каждом шаге цена текущего товара добавляется к сумме.

В проекте `reduce` пригодится для корзины и расчёта общей суммы заказа.

Корзина будет дополнительным или повышенным уровнем для контрольной работы №4, но базовый принцип расчёта суммы полезно понять заранее.

### 5.12. Поиск по названию товара

Поиск по названию можно реализовать через `filter`.

Пример:

```javascript
function searchProducts(products, query) {
  const normalizedQuery = query.trim().toLowerCase();

  if (normalizedQuery === '') {
    return products;
  }

  return products.filter((product) => {
    return product.title.toLowerCase().includes(normalizedQuery);
  });
}
```

Пояснение:

- `trim()` убирает лишние пробелы по краям строки;
- `toLowerCase()` приводит строку к нижнему регистру;
- `includes()` проверяет, содержит ли название товара поисковую строку;
- если строка поиска пустая, функция возвращает все товары.

Такой подход нужен для будущего поля поиска в каталоге.

### 5.13. Фильтрация по категории

Фильтрация по категории также выполняется через `filter`.

```javascript
function filterProductsByCategory(products, category) {
  if (category === 'all') {
    return products;
  }

  return products.filter((product) => {
    return product.category === category;
  });
}
```

Пояснение:

- если выбрана категория `all`, возвращаются все товары;
- иначе возвращаются только товары выбранной категории.

В следующей практической работе эта функция будет связана с элементом `select` или кнопками фильтра.

### 5.14. Сортировка товаров

Сортировку удобно оформить как отдельную функцию.

```javascript
function sortProductsByPrice(products, direction = 'asc') {
  const productsCopy = [...products];

  if (direction === 'desc') {
    return productsCopy.sort((a, b) => b.price - a.price);
  }

  return productsCopy.sort((a, b) => a.price - b.price);
}
```

Пояснение:

- функция принимает массив товаров;
- создаёт копию массива;
- если направление `desc`, сортирует по убыванию;
- в остальных случаях сортирует по возрастанию.

Сортировать копию безопаснее, потому что исходный массив не меняется.

### 5.15. Расчёты для каталога и корзины

В интернет-магазине часто нужно считать:

- количество товаров;
- количество товаров в наличии;
- среднюю цену;
- общую стоимость выбранных товаров;
- итоговую цену со скидкой.

Пример подсчёта товаров в наличии:

```javascript
function countAvailableProducts(products) {
  return products.filter((product) => product.isAvailable).length;
}
```

Пример расчёта общей стоимости:

```javascript
function calculateTotalPrice(products) {
  return products.reduce((sum, product) => {
    return sum + product.price;
  }, 0);
}
```

В КР №4 корзина может быть самостоятельной доработкой. Но логика корзины строится на тех же принципах:

- массив выбранных товаров;
- добавление товара;
- удаление товара;
- пересчёт суммы;
- отображение количества товаров.

### Перед заданием. Учебная лаборатория массивов

Выполняйте каждый кодовый блок отдельно в Console. Сначала спрогнозируйте результат, затем запустите, сравните вывод и измените исходные данные. Не переносите код каталога в свой проект до проверки отдельных методов.

#### Учебная лаборатория: от индекса к callback

Прежде чем обрабатывать шесть товаров, запустите следующие независимые блоки в Console по одному. Перед каждым вызовом запишите прогноз. После проверки поменяйте указанные данные; блоковые фигурные скобки позволяют запускать примеры независимо без конфликта имён.

```javascript
{
  const names = ['Лампа', 'Книга', 'Чашка'];
  console.log(names[0]);      // Лампа: первый индекс равен 0
  console.log(names.length);  // 3
  for (let index = 0; index < names.length; index += 1) {
    console.log(index, names[index]);
  }
}
```

Предскажите, что даст `names[3]`, затем проверьте: `undefined`. Измените условие цикла на `index <= names.length` только для опыта, найдите лишнюю итерацию и верните правильное условие. Самостоятельно выведите те же названия через `for...of` без индекса.

```javascript
{
  function printValue(value) { console.log('Значение:', value); }
  function visit(values, action) {
    for (const value of values) action(value);
  }
  visit([2, 4], printValue); // Значение: 2; Значение: 4
}
```

`printValue` передаётся как значение, а `visit` вызывает его позднее для каждого элемента. Такую переданную функцию называют callback. Предскажите, что изменится после замены массива на `[2, 4, 6]`; проверьте три вызова. Затем выполните `[2, 4, 6].forEach((value) => console.log(value))`: `forEach` сам вызывает callback для каждого числа и не создаёт новый массив результата.

#### Учебная лаборатория: один метод — один результат

Запускайте каждый блок отдельно. В таблице наблюдений для каждого метода запишите вход, значение, которое возвращает callback, результат метода и изменился ли исходный массив. Лишь после этих опытов переходите к функциям каталога.

```javascript
{
  const prices = [100, 200, 300];
  const discounted = prices.map((price) => price - 10);
  console.log(discounted); // [90, 190, 290]
  console.log(prices);     // [100, 200, 300]
}
```

`map` передаёт callback очередную цену и собирает каждое возвращённое число в новый массив. Предскажите результат скидки 20, затем измените выражение и проверьте, что исходные цены остались прежними. Самостоятельно получите массив строк вида `'100 руб.'`.

```javascript
{
  const prices = [100, 200, 300];
  const expensive = prices.filter((price) => price >= 200);
  console.log(expensive); // [200, 300]
  console.log(prices);    // [100, 200, 300]
}
```

Callback `filter` возвращает условие: в новый массив попадают только элементы с `true`. Сначала предскажите результат порога 400, потом проверьте пустой массив. Самостоятельно отберите цены меньше 250.

```javascript
{
  const prices = [100, 200, 300];
  const found = prices.find((price) => price > 150);
  console.log(found); // 200 — первый подходящий элемент
  console.log(prices.find((price) => price > 400)); // undefined
}
```

`find` возвращает один первый элемент или `undefined`, а не массив. Измените условие на `price > 250`, предскажите результат и проверьте. Перед чтением свойства найденного товара в проекте проверяйте, что он существует.

```javascript
{
  const prices = [30, 5, 12];
  const sorted = [...prices].sort((first, second) => first - second);
  console.log(sorted); // [5, 12, 30]
  console.log(prices); // [30, 5, 12]
}
```

`sort` изменяет массив, на котором вызван; здесь это копия, созданная `[...prices]`. Callback-компаратор возвращает отрицательное, нулевое или положительное число, определяя относительный порядок двух элементов. Измените его на `second - first`, предскажите убывание и проверьте. Затем отдельно попробуйте `prices.sort(...)` и наблюдайте изменение исходного массива.

```javascript
{
  const prices = [100, 200, 300];
  const total = prices.reduce((sum, price) => sum + price, 0);
  console.log(total); // 600
  console.log([].reduce((sum, price) => sum + price, 0)); // 0
}
```

`reduce` передаёт callback накопленную сумму и очередную цену; возвращённая сумма становится накопителем следующего шага. Запишите промежуточные значения 0 → 100 → 300 → 600. Добавьте цену 50, предскажите 650 и проверьте. Самостоятельно посчитайте количество положительных чисел через числовой накопитель.

**Проверка перед проектом:** для `forEach`, `map`, `filter`, `find`, `sort` и `reduce` назовите вход callback, возвращаемое значение и влияние на исходный массив. Только после этого выполняйте этапы обработки товаров ниже.

## 14. Типичные ошибки

| Ошибка | Почему возникает | Как исправить |
|---|---|---|
| Товары имеют разные свойства | Студент создаёт объекты без единой структуры | Проверить, что у всех товаров есть одинаковые ключи |
| Используется один объект вместо массива | Не выполнен переход от одного товара к каталогу | Создать `const products = [...]` |
| В консоли ошибка `products is not defined` | `data.js` не подключён или подключён позже `main.js` | Проверить порядок подключения скриптов |
| Поиск не работает из-за регистра | Строки сравниваются без `toLowerCase()` | Привести и запрос, и название к нижнему регистру |
| Поиск не работает из-за пробелов | Не используется `trim()` | Очистить строку поиска через `trim()` |
| Фильтр по категории ничего не возвращает | Категория написана по-разному | Использовать одинаковые значения категорий |
| `sort` меняет исходный массив | Сортировка выполнена напрямую | Сортировать копию через `[...products]` |
| После `find` код падает | Не проверяется `undefined` | Добавить проверку `if (productById)` |
| `reduce` считает неправильно | Не задано начальное значение | Использовать `0` как начальное значение суммы |
| Данные выводятся через `innerHTML` | Студент копирует небезопасный подход | Для текста использовать `textContent` |
| `README` не обновлён | Студент сделал только код | Описать массив, функции и результаты проверки |
