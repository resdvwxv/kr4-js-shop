# Практика #16 — Массив товаров, поиск, фильтрация, сортировка и расчёты

## Цель и навыки

**Цель:** заменить один объект товара на массив товаров и подготовить основу для поиска, фильтрации, сортировки и расчётов в контрольной работе №4.

**Навыки:** условия `if`/`else`, циклы `for`/`for...of`, методы массивов `forEach`, `map`, `filter`, `find`, `sort`, `reduce`, поиск, фильтрация, сортировка, расчёты.

## Краткая теория

### 5.1. Зачем массив товаров

Список товаров удобно хранить в массиве:

```javascript
const products = [
  { id: 1, title: 'Кофемашина Barista Home', category: 'kitchen', price: 19990, isAvailable: true },
  { id: 2, title: 'Электрический чайник SmartHeat', category: 'kitchen', price: 4990, isAvailable: true }
];
```

Массив позволяет: перебрать, найти, отфильтровать, отсортировать и посчитать.

### 5.2. Структура объекта товара

Каждый товар должен иметь одинаковую структуру:

| Свойство | Назначение |
|---|---|
| `id` | уникальный идентификатор товара |
| `title` | название товара |
| `category` | категория товара |
| `price` | цена товара |
| `discountPercent` | скидка в процентах |
| `rating` | рейтинг товара |
| `isAvailable` | наличие товара |

### 5.3. Условный оператор `if`

```javascript
if (product.isAvailable) {
  console.log('Товар в наличии');
} else {
  console.log('Товара нет в наличии');
}
```

Используется для проверки наличия, скидки, категории, строки поиска.

### 5.4. Цикл `for`
```javascript
for (let i = 0; i < products.length; i += 1) {
  console.log(products[i].title);
}
```

### 5.5. Цикл `for...of`

```javascript
for (const product of products) {
  console.log(product.title);
}
```

### 5.6. Метод `forEach`
```javascript
products.forEach((product) => console.log(product.title));
```

### 5.7. Метод `map`
```javascript
const titles = products.map((p) => p.title);
```

### 5.8. Метод `filter`
```javascript
const available = products.filter((p) => p.isAvailable);
```

### 5.9. Метод `find`
```javascript
const found = products.find((p) => p.id === 2);
```

### 5.10. Метод `sort`
Сортирует (изменяет исходный, поэтому сортируйте копию):
```javascript
const sorted = [...products].sort((a, b) => a.price - b.price);
```

### 5.11. Метод `reduce`
```javascript
const total = products.reduce((sum, p) => sum + p.price, 0);
```

## Ключевые функции каталога

### Поиск по названию

```javascript
function searchProducts(products, query) {
  const normalizedQuery = query.trim().toLowerCase();
  if (normalizedQuery === '') return products;
  return products.filter((p) => p.title.toLowerCase().includes(normalizedQuery));
}
```

### Фильтрация по категории

```javascript
function filterProductsByCategory(products, category) {
  if (category === 'all') return products;
  return products.filter((p) => p.category === category);
}
```

### Сортировка по цене

```javascript
function sortProductsByPrice(products, direction = 'asc') {
  const copy = [...products];
  if (direction === 'desc') return copy.sort((a, b) => b.price - a.price);
  return copy.sort((a, b) => a.price - b.price);
}
```

### Расчёты

```javascript
function countAvailableProducts(products) {
  return products.filter((p) => p.isAvailable).length;
}

function calculateTotalPrice(products) {
  return products.reduce((sum, p) => sum + p.price, 0);
}

function calculateAveragePrice(products) {
  if (products.length === 0) return 0;
  return Math.round(calculateTotalPrice(products) / products.length);
}
```

### Комбинирование поиска + фильтра + сортировки

```javascript
function getPreparedProducts(products, query, category, sortDirection) {
  let result = [...products];
  result = searchProducts(result, query);
  result = filterProductsByCategory(result, category);
  result = sortProductsByPrice(result, sortDirection);
  return result;
}
```
