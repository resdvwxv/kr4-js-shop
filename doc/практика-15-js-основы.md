# Практика #15: Подключение JavaScript к интернет-магазину

## Цель и навыки

**Цель:** создать репозиторий `kr4-js-shop` на основе КР №3 и подключить первые JavaScript-файлы.

**Студент должен:**

- создать репозиторий `kr4-js-shop` и папку `js/` с файлами `data.js`, `main.js`;
- подключить скрипты к HTML через `defer`;
- создать объект товара;
- написать функции форматирования цены, расчёта скидки, определения статуса и описания;
- вывести данные в консоль и на страницу безопасным способом (`textContent`);
- объяснить в `README.md`, почему `textContent` безопаснее `innerHTML`.

## Паттерн проекта

```
Данные → функции обработки → состояние → рендер → события → обновление → повторный рендер
```

На этой практике — первые два элемента: **данные** (объект товара) и **функции** (расчёты).

## Теория

### Что такое JavaScript

| Роль | Что задаёт |
| --- | --- |
| HTML | структуру |
| CSS | внешний вид |
| JavaScript | поведение (поиск, фильтрация, модальные окна, валидация, корзина) |

Подключается через `<script src="js/main.js" defer></script>`. Атрибут `defer` — выполнить после разбора HTML. Порядок важен: `data.js` до `main.js`.

### Консоль

```js
console.log('Сообщение');
console.warn('Предупреждение');
console.error('Ошибка');
console.table({ title: 'Товар', price: 19990 });
```
### Почему не `alert()` / `prompt()`

Блокируют страницу, не связаны с HTML-формами, нельзя стилизовать. В проекте — вывод в DOM-элементы через `textContent`.

### Переменные

```js
const shopName = 'Магазин';   // не переназначается
let cartCount = 0;             // переназначается
```
**Правило:** `const` по умолчанию, `let` если меняется, `var` не использовать.

### Типы данных

| Тип | Пример | Где используется |
| --- | --- | --- |
| `string` | `'Кофемашина'` | название, категория, сообщение |
| `number` | `19990` | цена, скидка, количество |
| `boolean` | `true` | наличие товара |
| `null` | `null` | значения пока нет |
| `undefined` | `undefined` | значение не задано |
| `object` | `{ title: 'Товар' }` | товар, заявка |
| `array` | `[p1, p2]` | список товаров |

### Объект товара

```js
const product = {
  id: 1,
  title: 'Кофемашина Barista Home',
  category: 'kitchen',
  price: 19990,
  discountPercent: 10,
  rating: 4.7,
  isAvailable: true
};
```
Обращение: `product.title`, `product.price`.

### Операторы

**Арифметические:** `+` сложение, `-` вычитание, `*` умножение, `/` деление, `%` остаток.

**Сравнения:** `>` `<` `>=` `<=` `===` строго равно `!==` строго не равно. Использовать `===` — без неявного преобразования типов.

**Логические:** `&&` И, `||` ИЛИ, `!` НЕ.
### Условный оператор

```js
if (product.isAvailable) {
  console.log('В наличии');
} else {
  console.log('Нет в наличии');
}
```
### Функции

```js
function formatPrice(price) {
  return `${price} руб.`;
}
```

**Правило:** использовать `return`, а не `console.log` — результат нужен для дальнейшего использования.
### Область видимости

```js
const title = 'Кофемашина';          // доступна внутри функций

function showTitle() {
  const msg = `Товар: ${title}`;    // msg только внутри функции
  console.log(msg);
}
```

**Правило:** не создавать лишние глобальные переменные, выносить повторяющуюся логику в функции.
### Безопасный вывод (ключевое)

```js
// ❌ Небезопасно — пользовательский HTML выполнится
element.innerHTML = userInput;

// ✅ Безопасно — выводит как обычный текст
element.textContent = userInput;
```

**Правила:**

- для пользовательских данных — `textContent`;
- для создания элементов — `document.createElement()`;
- для классов — `classList`;
- не использовать `innerHTML` для данных от пользователя.

## Функции проекта

```js
function formatPrice(price) {
  return `${price} руб.`;
}

function calculateDiscount(price, discountPercent) {
  return price * discountPercent / 100;
}

function calculateFinalPrice(price, discountPercent) {
  const discountValue = calculateDiscount(price, discountPercent);
  return price - discountValue;
}

function getProductStatus(product) {
  if (product.isAvailable) return 'В наличии';
  return 'Нет в наличии';
}

function createProductSummary(product) {
  const finalPrice = calculateFinalPrice(product.price, product.discountPercent);
  const status = getProductStatus(product);
  return `${product.title}: ${formatPrice(finalPrice)}. Статус: ${status}.`;
}
```

## Безопасный вывод на страницу

```js
const messageEl = document.querySelector('.js-message');
const outputEl = document.querySelector('.product-output');

if (messageEl) messageEl.textContent = 'JavaScript подключён корректно.';
if (outputEl) outputEl.textContent = productSummary;
```

Проверки `if (element)` защищают от ошибок на страницах без нужного элемента.
