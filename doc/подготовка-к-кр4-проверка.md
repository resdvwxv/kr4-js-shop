## 1. Чек-лист подготовки проекта

### Структура проекта
- [ ] Репозиторий `kr4-js-shop` (отдельный, на основе интернет-магазина)
- [ ] Страницы: `index.html`, `catalog.html`, `product.html`, `order.html`, `contacts.html` (+ `cart.html`)
- [ ] `js/`: `data.js`, `catalog.js`, `validation.js`, `main.js` (+ `cart.js`, `modal.js`)
- [ ] `css/`, `images/`, `README.md`, `.gitignore`

### Массив товаров (`data.js`)
- [ ] 8–12 товаров, единая структура: `id`, `title`, `category`, `price`, `isAvailable`
- [ ] `id` уникальны, `price` — числа

### Каталог (`catalog.html`)
- [ ] Карточки через `createElement()`
- [ ] Поиск (`input`), фильтр по категории (`change`), сортировка
- [ ] Пустое состояние при отсутствии результатов

### Форма (`order.html`)
- [ ] Валидация: пустые поля, email, телефон
- [ ] Ошибки на странице, не через `alert()`

### Безопасность и события
- [ ] `textContent` вместо `innerHTML` для пользовательских данных
- [ ] `addEventListener()` вместо inline-обработчиков

### README и консоль
- [ ] Описание JS-файлов, функций, доработок, ФИО и группы
- [ ] Нет ошибок в DevTools Console на всех страницах

## 3. Типичные ошибки

| Ошибка | Почему | Как исправить |
|---|---|---|
| Проект с пустой страницы | Не понята связь с предыдущими КР | Создать `kr4-js-shop` на основе магазина |
| Товаров меньше 8 | Использован учебный массив | Расширить до 8–12 |
| Карточки в HTML вручную | Не выполнена генерация через JS | `createElement()` |
| Поиск только после перезагрузки | Нет обработчика `input` | `addEventListener('input', ...)` |
| Фильтр не работает | Категории не совпадают | Сверить `product.category` и `option value` |
| Сортировка ломает порядок | `sort()` на исходном массиве | `[...products].sort(...)` |
| Ошибки через `alert()` | Скопирован старый подход | DOM через `textContent` |
| `innerHTML` для пользовательских данных | Не учтена безопасность | `textContent`, `createElement`, `append` |
| Скрипт падает на другой странице | Ищет отсутствующий элемент | `if (element)` проверки |
| README не описывает JS | Документация не обновлена | Добавить описание файлов и функций |
| Не может объяснить код | Код скопирован | Разобрать функции и сценарии |
